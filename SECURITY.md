# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this project, please report it responsibly.

**Do not open a public GitHub issue for security concerns.**

Instead, please email: **security@transilience.ai**

Include the following in your report:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 5 business days
- **Fix or mitigation**: Depends on severity, but we aim for prompt resolution

## Scope

This policy applies to:

- The video generation pipeline (`project/videogen/`)
- The frontend application (`project/videogen/frontend/`)
- The Modal deployment (`modal_app.py`)
- API endpoints

## Best Practices for Contributors

- Never commit API keys, secrets, or credentials
- Use environment variables for all sensitive configuration
- Keep dependencies up to date
- Follow the principle of least privilege for API access

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |

Thank you for helping keep this project and its users safe.
